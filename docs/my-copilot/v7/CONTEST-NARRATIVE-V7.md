# 공모전 서사 V7 — 양식 02 · PPT 2차 시안의 논리 (2026-11-10)

> 기준: `PRODUCT-VISION-V7.md`. 1차 시안(2026-11-10, 14장 · 고객 편의 중심)은 `docs/presentation/MY-CO-PILOT_1차시안.pptx` 로 남긴다.

## 원칙

1. **첫 30초 안에** "현대차에 이미 있는 기능을 다시 만든 앱"이라는 오해를 끊는다 — 2장에서 문제, 3장에서 관계.
2. 주인공은 **Journey Goal**. 가족 모드·충전이 주인공이 되지 않게 한다. EV 는 9장 하나.
3. ARRIVE READY 는 **신규 대표 경험이자 계획**이다. 목업에는 "목표 UX · 가상 수치", 상태에는 [미구현]을 붙인다. (2026-11-12 오너 결정: ARRIVE READY 는 **[개발 중] — 실제 주차 데이터 · 내비 소요 시간 검증 · 판단 엔진 구현(개발 브랜치 · 출품 APK 미포함) · 통합 화면 · 실행 흐름 개발 중**)
4. 이미 동작하는 것(픽업 Mission · 차량 제어 · 내비 실행 · EV 통합)은 **기술 기반 실증**으로 압축한다.
5. 검증된 강점 — **승인 → 실행 → 재조회 확인** — 을 크게.
6. 개선율·리텐션·사용자 수치를 만들지 않는다. MAU 는 계산 시나리오로만.
