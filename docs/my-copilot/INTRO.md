## 한 문장

**목적지를 알려주는 차에서, 목적을 달성하도록 돕는 차로.**
MY CO-PILOT 은 차량 상태 · 내비게이션 · 외부 서비스의 정보를 연결해 운전자의 실제 이동 목표를 달성하는 데 필요한 다음 행동을 판단하고, 승인된 행동의 실행 결과까지 확인하는 차량용 코파일럿입니다.

## 푸는 문제 — 도착 ≠ 성공

오후 3시 고객사 미팅의 목적은 건물 앞 도착이 아니라 **약속 시간에 맞춰 주차하고 방문하는 것**입니다. 내비는 경로를 잘 압니다. 주차 가능성 · 운영시간 · 방문 여유는 운전자가 여러 앱을 오가며 이어 붙입니다. 아이 픽업도, 가족 장거리도 같은 구조입니다.

## 하나의 엔진, 세 가지 경험

**Journey Goal Engine** — 목표 → 필수 조건 → 데이터 → 조건 위반 후보 제거 → 추천 하나 + 대안 → 승인 → 공식 SDK 실행 → **재조회로 반영 확인** → 목표 갱신.

| 경험 | 상태 |
|---|---|
| **ARRIVE READY** — 약속 시간 + 이동 + 주차 + 방문 (모든 동력원 · 신규 주력) | **[미구현]** — 기능 미구현 · 데이터 관문 통과 — 서울 시영 주차장 105곳 실시간 대수 · 위치 [실 API], 주차장까지 소요 시간 · 주차장을 목적지로 요청 · 재조회 [에뮬] |
| **JOURNEY RECOVERY** — 근거가 바뀌면 결과가 달라질 때만 재제안 | 충전소 상태 · 배터리 변화 재판단 [에뮬] · 주차·시간 [미구현] |
| **ENERGY & STOP** — 충전과 휴식을 한 결정으로 (전기차 특화) | 배터리·내비 [에뮬] · 공공 충전소 [실 API] · 휴게소 시설 [시연] |

## 이미 동작하는 기반

**① 목표를 끝까지 기억 — 아이 픽업 후 귀가 [에뮬]**: 다른 설정만 승인 한 번 → 재조회로 "적용 확인" → 학원에 도착해도 귀가를 기억 → "집으로 안내 시작" 한 번 → 내비 목적지 재조회 → 앱이 꺼져도 이어짐. (도착 전환은 모의 주행 — 이 에뮬레이터 이미지에 속도 신호가 없다.)
**② 여러 서비스를 한 결정으로 — ENERGY & STOP**: 도착 후 대기까지 센 에너지로 "서야 하나"를 먼저 판단 → 공공 충전소 상태 · 도달 가능성 · 동승자 조건으로 추천 하나 + 대안 둘 → 내비 경유지 → 목록 재조회.

## 기존 기능과의 관계

기본 내비(경로 · 충전 계획) · Gleo AI(명령 수행) · 차량 설정(시트 프리셋 · 사전 공조)을 **대체하지 않습니다.** 운전자가 정한 목표에 대해 여러 서비스의 조건을 함께 거르고, 승인한 일의 반영 결과까지 확인하는 층입니다. 자체 지도 · 턴바이턴 · 범용 장소·주차장 검색 · 범용 챗봇은 만들지 않습니다.

## 지키는 것

자동으로 경로를 바꾸지 않는다 · 예상 도착 시각 · 도보 시간 · 빈자리를 만들어 내지 않는다(근거 없으면 "판단할 정보가 부족해요") · 에너지는 범위와 "추정"으로 · 주행 중에는 한 줄과 음성만 · 실제와 시연을 섞어 말하지 않는다.
