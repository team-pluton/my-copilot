## 읽는 법

- **차량 값은 전부 시연 데이터다.** 웹 시뮬레이터에는 실제 차량 연결이 없다(정책 4).
- **고정한 테스트**의 따옴표 안은 실제 테스트 이름(앞부분)이다 — 자동 생성 시 `core/src/test/.../assistant/` 에서 확인했다.
- 같은 판단을 Pleos Connect 차량용 앱(`android/copilot`)이 같은 세션 규칙(`core/.../CopilotSession.kt`)으로 낸다. 에뮬레이터에서 실제로 본 것은 시나리오마다 **에뮬레이터** 칸에 따로 적었다 — 근거는 `v5/SDK-EVIDENCE-V5.md`, `EMULATOR-RESULT-2026-10-29.md`.
- 이 에뮬레이터 이미지에는 속도 신호가 없다. 주행·도착 전환을 에뮬레이터에서 보인 경우는 개발용 **모의 주행** 스위치를 쓴 것이다 — 주행 자동 인식에 성공했다고 말하지 않는다.
- 내비 목적지를 앱이 설정하는 장면은 없다(공식 API 미확인). 경유지 추가는 사용자가 고르고 콜백으로 확인한다.

| 4 | 주차 — 그래도 모름 | 주차했지만 앱은 기어를 모르니 단계를 바꾸지 않고, 주행 제한도 풀지 않습니다(보수적). |

| 6 | 주행 신호·공조 연결 복구 | 나머지 연결이 돌아오면 그제야 주차 상태를 알고 단계를 바꿉니다. 에너지는 다시 판단하지 않습니다(입력이 안 바뀌었으니까). |

## 갱신

시나리오 단계를 코드에서 바꾸면 이 문서도 다시 뽑는다(단계 수가 다르면 문서가 낡은 것이다). 단계 문구는 사람이 고쳐 쓰지 않는다 — 코드와 어긋나면 시연이 문서와 다르게 보인다.

```
python -X utf8 -I scripts/copilot-scenarios/extract.py src/components/copilot/copilot-sim.tsx <임시>/scenarios.json
python -X utf8 -I scripts/copilot-scenarios/render.py <임시>/scenarios.json docs/my-copilot/SCENARIOS.md
```

시나리오별 설명(Mission · 보여 주는 것 · 테스트 · 에뮬레이터)은 `render.py` 의 META 에 있다 — 시나리오를 더하면 거기에도 한 줄 더한다.
