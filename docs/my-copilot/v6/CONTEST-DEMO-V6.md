# 공모전 시연 안 V6

**아직 촬영 전이다.** 충전소 실데이터 없이 찍으면 자막에 시연 데이터라고 적어야 한다.

## 말할 수 있는 것 (지금)

- 실제 차량 값으로 충전 필요를 판단한다(에뮬레이터)
- 승인하면 실제 내비에 경유지가 들어가고 재조회로 확인한다(에뮬레이터)
- 칸이 차면 고르게 하고 고른 칸만 바꾼다(에뮬레이터)
- 충전소 정보가 없으면 추천하지 않는다(에뮬레이터)

## 말하면 안 되는 것 (지금)

- 실제 충전소 상태로 추천한다 — 키 전까지 거짓이다
- 조작 N회 감소 · N% 단축 — 측정 전
- 빈 충전기 보장 · 전 차종 지원 · 현대차에 없는 기능
- 실차 동작

## 60초 안

| 초 | 장면 | 자막 |
|---|---|---|
| 0~10 | 가족 · 부산 선택 | 동승자는 직접 선택 |
| 10~25 | 결정 카드 | 배터리 실제 값 · 충전기 [실제/시연 표기] |
| 25~40 | 경유지 승인 → 내비 반영 → 확인 | 실제 내비 |
| 40~50 | 상태 변화 → 대안 | 기록값 재현 |
| 50~60 | 주행 중 한 줄 | 모의 주행 |

## 비교 측정 (PT 전)

같은 과제로 기본 내비 / 내비 + 폰 앱 / V6 를 정차 상태에서 비교한다. 앱 전환 · 조작 · 결정 시간 · 결정 실패. 절차는 `docs/my-copilot/eval/`. 평가자 수를 그대로 적는다.

## 출품본과의 관계

1차 출품은 쉼표 DRIVE v3.1 이다(오너 결정). V6 는 별도 브랜치이고 양식 02·APK 에 들어가지 않았다. 지시서의 "구현 범위를 반영한 제안서"는 만들지 않았다 — 출품 양식을 바꾸는 일이라 오너 결정이 먼저다.
