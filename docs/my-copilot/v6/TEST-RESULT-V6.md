## 위험

### 1. 🔴 출품 앱이 에뮬레이터에서 잘못 판단한다

실제 차량 신호 연결 상태에서 "배터리 용량 77400 kWh", 400km 주행 소비 0%, "충분"(`E25-01`, `E25-02`). 2차 PT 는 실제 동작 시연이 필수다. **오너 지시로 고치지 않았다.** 후보 수정은 어댑터 한 줄이다.

### 2. 🟠 V5 경로 교체 확인

`copilot-v5` 의 "집으로 안내 시작"은 `isRouting` 을 믿어 기존 경로를 확인 없이 덮을 수 있다. V6 에서 고쳤으나 교체 확인 화면은 실행으로 보지 못했다.

### 3. 🟠 충전소 데이터는 키 전까지 미검증

코드표 · 상태 정확도 · 연결표 · 호출 한도 모두 미확인.

### 4. 🟡 위치가 수기 목록

휴게소 경로 km 는 측정값이 아니다. `requestTrip` 연결로 개선 가능.

### 5. 🟡 메모리

PC 가상 메모리 부족으로 빌드·에뮬레이터가 여러 번 죽었다. 시연 PC 준비가 필요하다.
