# UX FLOW V5 — 최초·반복 이용 흐름과 탭 수 (2026-11-02)

지시서 8절: "모드를 설정하는 앱"에서 "현재 이동을 이해하는 화면"으로. 기존 한 화면 UX(2026-10-28)는 보존하고 **정보 우선순위**만 바꿨다.

## 1. 화면 위계(웹 `/copilot` · 차량용 앱 홈 — 같은 구성)

```
최상단   Mission 머리줄 — "픽업 후 귀가 · 차 안에서 대기"
         복귀 줄(있을 때만) — "귀가 집 (귀가) 일정 기억 중 · 방문 뒤에도 끝나지 않음" / 확인 뒤 "귀가 일정은 기억하고 있어요 · 이동을 시작하려면 내비게이션에서 집 (귀가)를 목적지로 설정해 주세요"
         대기 줄(있을 때만) — "도착 후 대기 20분 · 저장된 계획" / "직접 확인" / "미확인 · 대기 소비는 계산에 없음"
중앙     코파일럿의 다음 행동 하나 — 출발 준비 카드(승인 하나) 또는 제안 하나(위험 → 결정 → 단계 → 주의)
하단     차량 상태 칩(차량 · 여정) + 지금 상황 한 줄("학원까지 12km · 도착 후 20분 대기 · 배터리 68%")
상세     "자세히" 한 버튼 뒤 — 근거 · 출처 · 추천함 · 에너지 계산 · 프로필 · 기록 (기존 그대로)
```

주행 중에는 한 줄 화면만(변경 없음). 정상 이동에서는 알림 없음.

## 2. 최초 이용(저장 기록 없음)

| 단계 | 화면 | 탭 |
|---|---|---|
| 탑승 | "오늘은 누구와 함께 가시나요?" 혼자 · 가족 · 동승자 (+ 작은 칩: 혼자 · 업무 이동 / 가족 · 아이 픽업 후 귀가) · 운전자(선택) | 1 (+운전자 1) |
| 준비 | 저장 취향 vs 차량 설정 자동 비교 → 다른 것만 "N개 한 번에 적용" | 1 |
| 출발 | — | 0 |
| 도착(중간) | "하차 준비를 시작할까요?"(체크리스트 있을 때만) → 확인 | 1~ |
| 대기·방문 | "방문이 끝났나요? 귀가 일정을 확인할까요?" → 귀가 일정 확인(내비 목적지는 바뀌지 않음) | 1 |
| 귀가 출발 | — (차가 출발하면 귀가 구간) | 0 |
| 집 도착 | 하차 확인 → 이동 마치기 | 1~ |

"지난번처럼"은 **실제 저장 기록**(vault.lastMode · lastDriver)이 있을 때만 맨 위에 뜬다. 시연 프리셋의 이름(거래처·학원)은 시연 데이터다.

## 3. 반복 이용

- "지난번처럼 · 엄마 · 아이 픽업 후 귀가" 1탭 → 비교·준비 자동.
- 저장된 복귀 목적지·대기 시간(저장된 계획)을 재사용 — 바꾸면 "직접 확인"으로 표시.
- 취향 학습 후보(3번 반복)는 출발 준비에서 한 번만 묻는다(기존).

## 4. 앱 재시작 · 백그라운드 복귀

- 백그라운드 복귀: 상태는 ViewModel 이 들고 있다(기존) — 0탭.
- 프로세스 종료 뒤 재시작: 진행 중(출발 준비 이후 · 완료 전)이면 **자동으로 이어서**(0탭) + 토스트 "이동 #n 를 이어서 합니다 · HH:MM 저장" + 기록 한 줄. 진행 중이던 제어 요청은 복원하지 않는다.
- 끝난 이동·고르기 전이면 처음 화면.

## 6. "귀가 확인"과 "내비 목적지 설정"은 다른 상태다 (오너 결정 2026-11-03 ④)

| 상태 | 누가 아나 | 화면 |
|---|---|---|
| Mission 이 귀가 일정을 기억함 | 앱(저장된 왕복 계획) | "귀가 집 (귀가) 일정 기억 중" |
| 사용자가 귀가 일정을 확인함 | 앱(NEXT_LEG 수락) | 단계 "귀가 확인 · 내비 미설정" + "이동을 시작하려면 내비게이션에서 집 (귀가)를 목적지로 설정해 주세요" · 토스트 "내비 목적지는 아직 설정되지 않았습니다" |
| 내비 목적지가 실제로 설정됨 | 내비 — **앱은 모른다**(목적지 조회·설정 API 미배선·미확인) | 앱은 "설정됨"이라고 쓰지 않는다 |

"준비됨"이라는 말은 쓰지 않는다 — 경로까지 준비된 것으로 읽힌다.

## 7. 바꾸지 않은 것

출발 준비 카드(실내 비교 · 승인 하나 · 준비물 · 에너지 한 줄) · 주행 중 한 줄 · 하차 화면 · 자세히 · 기록 · 프로필 화면. 새 탭·새 설정 메뉴 없음.
