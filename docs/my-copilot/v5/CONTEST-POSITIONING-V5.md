# CONTEST POSITIONING V5 — 공모전 심사 기준 대응 (2026-11-02)

심사 기준(`docs/00-contest.md`, 공식 홈페이지 2026-10-25): 1차 **차량특화성 · 창의성 · 기술 활용성 · 사업성** + 개발 산출물 가산점 · 2차 PT **실제 동작하는 앱 시연**. 배점 비공개.

> 1차 접수(11/15)의 출품작은 **쉼표 DRIVE v3.1 그대로**다(오너 결정 2026-10-26). V5 는 `copilot-v5` 브랜치에만 있고 **master 에 합치지 않는다**(오너 결정 2026-11-03 ①). 이 문서는 "만약 V5 로 말한다면"의 대응표다.

**포지셔닝 한 줄(2026-11-03)**: MY CO-PILOT 은 편의 기능을 묶은 앱이 아니라 **목적을 기억해 여정을 이어 주는 앱**이다 — 하나의 이동 목적 아래에서 차량 준비 · 여정 판단 · 동승자 조건 · 도착 후 남은 일정이 연결된다. 귀가 알림 하나가 가치가 아니다.

## 말하지 않는 것

"내비 목적지 자동 설정"(공식 API 미확인 · 구현 안 함) · "에뮬레이터에서 주행 자동 인식" · "AI 가 알아서" · "동승자 자동 감지" · "운전자 자동 인식" · "음악 자동 재생" · "원격 준비" · "피로 측정" · 확인 전의 "제어 완료" · "전 차종 지원 완료"(차종별 Capability 미검증) · "실차에서 확인"(에뮬레이터뿐).

## 심사위원이 기억할 한 장면

"엄마가 '아이 픽업 후 귀가'를 고르자 운전석은 엄마 취향, 공조는 가족 취향으로 다른 것만 한 번에 맞추고, 차 안 대기 20분까지 세어 충전이 필요 없다고 판단하고, 학원에 도착해도 끝내지 않고, 아이가 나오면 귀가 일정을 한 번 확인하며 '내비게이션에서 집을 목적지로 설정해 주세요'라고 분명히 말하고, 앱이 꺼졌다 켜져도 그 자리에서 이어간다." — 60초 대본은 `DEMO-SCRIPT-V5.md`. 에너지 부족 판단은 가족 장거리(편도) 30초 사례로 따로.
