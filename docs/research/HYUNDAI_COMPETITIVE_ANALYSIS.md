## 3. 가장 중요한 발견 — 2026-10 인포테인먼트 업데이트 (전해 들음, 미확인)

외부 분석이 인용한 공식 업데이트 안내:
- 주행 **경로상의 장소 검색**
- 현재 경로 기준으로 실제 접근 가능한 장소 제시, 거리순
- 화장실·약국·주차장 등 주변 시설 탐색
- Gleo AI 로 음성 검색

| 기능 | 현대차 현재 | 쉼표 DRIVE v1 | v2 |
|---|---|---|---|
| 주변/경로상 장소 검색 | **제공** | 제공 예정 → **중복** | 쓰지 않는다 — 내비에 맡긴다 |
| 화장실·주차장 검색 | 제공 | 제공 예정 → 중복 | 동승자 조건으로 **골라 주는** 데만 쓴다 |
| 경유지 추가 | 제공 | 제공 예정 → 중복 | **수단**(NaviHelper)이지 차별화가 아니다 |
| AI 음성 장소 검색 | Gleo AI | 별도 구현 → 불필요 | 구현하지 않는다 |
| 사용자 설정 휴식 간격 | 확인되지 않음 | 핵심 | 유지(보조) |
| 동승자별 시설 조건 조합 | 확인되지 않음 | 핵심 | **유지 — 차별화 축 2** |
| **도착 후 차량 사용까지 포함한 에너지 예산** | 확인되지 않음 | 없음 | **차별화 축 1** |
| **충전 정차 = 휴식**으로 묶어 한 번에 계획 | 확인되지 않음 | 없음 | **차별화 축 3** |
| 미충족 조건 설명 | 확인되지 않음 | 일부 | 유지 |

"확인되지 않음"은 **없다는 뜻이 아니라** 검토한 자료에서 명시적으로 보이지
않았다는 뜻이다. **반드시 10/28 설명회 또는 실차·에뮬레이터에서 재확인.**

→ 결론: **장소 검색과 경유지 추가는 "우리가 만드는 것"에서 "우리가 쓰는 것"으로 내린다.**
차별화는 *무엇을 찾느냐*가 아니라 *언제·왜·누구를 위해 서느냐를 판단하는 층*에 둔다.

## 4. 마이현대 (전해 들음)

| 기능군 | 제공 | 기획 시 함의 |
|---|---|---|
| 차량 제어 | 도어·공조·경적·비상등 | 제어 앱은 중복 — 안 만든다 |
| 차량 상태 | 상태 확인 | **상태 표시만으로는 차별화 없음** (CAR TWIN 단독의 약점) |
| 운전 분석 | 패턴·연비·리포트 | 운전 점수 앱 중복 |
| 차량 관리 | 정비·소모품·예약 | 중복 |
| 주변 검색 | 충전소·맛집 | 일반 POI 중복 |
| EV | 충전소 탐색·배터리 관리 | **단순 충전소 추천은 중복** → "도착 후 사용" 이 차이 |
| 카라이프 | 세차·대리·주정차 | 중복 |

마이현대는 **차량 소유 이후의 생활 주기**, Pleos Connect 는 **탑승 중 실시간 경험**이다.
우리는 후자에만 선다.
