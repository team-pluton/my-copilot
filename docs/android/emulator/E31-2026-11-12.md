# E31 — ARRIVE READY 앱 연결 1차 실행 (2026-11-12, Pleos Connect Emulator v2.1.0 · 브랜치 `arrive-ready-v0` · debug)

목표(오너 2026-11-12): 실제 데이터로 추천 → 사용자 승인 → Pleos 내비 목적지 반영 → 내비에서 돌아와도 결과 유지 → 조건 변경 재판단.
**결과: 앞단(목표 카드 · 실데이터 주차 조회 · 판단 보류)까지만 확인. 에뮬레이터 내비가 이번 실행 내내 준비되지 않아 승인 → 내비 반영은 찍지 못했다.**

## 확인한 것

| 확인 | 결과 | 캡처 |

| 목표 카드 자리 | ✅ '업무 이동' → 출발 준비 화면의 **이번 이동의 목표** 카드(탭 아님) — 방문지(내비 목적지 쓰기 · 시연 위치) · 약속 60/75/90/120분 뒤 · 여유 5/10/15분 · "일정 앱 연동은 하지 않았어요" | E31-01 |

## 막힌 것 — 에뮬레이터 내비가 준비되지 않음

- 내비 앱 화면: "지도 정보를 불러오는 중입니다" ↔ "내비게이션 실행이 지연되고 있습니다 · 다시 시도"를 반복(E31-04)
- 그동안 NaviHelper 서비스는 연결되지만(`onServiceConnected` · 서비스 3.0.4) `requestRoute` · `requestTrip` · `getDestinationInfo` 에 **응답이 없다** — 우리 앱과 gateprobe(관문 B · C 를 통과했던 같은 코드) 모두
- 해 본 것: 에뮬레이터 재부팅 · `-gpu host -no-snapshot` 콜드 부트 · `emu geo fix`(이후 시간대가 PST → KST 로 바뀜) · 내비 '다시 시도' 여러 번 · 2분 이상 대기. 호스트 메모리 여유 4.2GB · 에뮬레이터 loadavg 6 — 메모리 부족 상태는 아니었다
- 로그: 내비 엔진은 돈다(맵매칭 · 타일 캐시) · `MapManager curMapView is null` · GPS NMEA 체크섬 경고 반복. 원인 미확인
- 같은 에뮬레이터에서 11-10(E27) · 11-11(E29) 에는 내비가 응답했다

## 다음 실행에서 할 것

1. 내비가 준비된 상태(지도 표시)를 먼저 확인 → gateprobe `op=state` 응답 확인
2. 내비에 방문지(광화문) 설정 → 카드 '내비 목적지 쓰기' → 약속 90분 뒤 → 판단(후보별 소요 시간) → 추천 승인
3. 교체 확인("지금 안내 중인 광화문 고객사 경로가 … 경로로 바뀌어요") → 바꾸기 → `requestRoute` → `onRouteStarted` → 목적지 재조회 → "내비 목적지를 …(으)로 설정했어요 · 내비가 확인함 · 주차 · 방문은 아직 기록하지 않아요"
4. 내비 화면으로 갔다가 셸 아이콘으로 돌아와 결과 유지 확인(D4 singleTask)
5. 다시 판단: 3분 주기 또는 '다시 확인' — 실데이터 변화가 없으면 개발용 만차 시연(화면에 '시연 데이터 포함')으로 알림 · 대안 제시 · "지금 경로 유지"
6. 거절 · 실패 · 응답 없음 경로

그래도 내비가 준비되지 않으면 AVD 데이터 초기화(`-wipe-data`)를 검토한다 — 내비 즐겨찾기 · 설치 앱이 지워지므로 오너 확인 뒤.

## 2차 시도(같은 날 오후) — 오너 승인으로 AVD 데이터 초기화 · 호스트 메모리 부족으로 중단

- `-wipe-data` 실행: 첫 번째는 "Insufficient RAM free"로 시작 거부 → `-memory 3072`(이번 실행만, AVD 설정은 그대로)로 **초기화 + 부팅 완료(95초)** → 직후 Windows 가 "가상 메모리 부족"(qemu 약 5GB 사용)으로 종료 → `-memory 2048` 은 GPU(Vulkan) 초기화에서 멈춤
- 원인: 호스트 **커밋 메모리 39.9 / 45.4GB** — 다른 프로젝트 개발 서버(Next dev 3007 · 3002, 11-10부터) · VS Code 창 여럿 · 11-10부터 떠 있는 Claude 세션 여러 개. 사용자 프로세스라 임의로 끄지 않았다
- 초기화로 지워진 것: 내비 즐겨찾기(집) · 설치 앱(출품 앱 · gateprobe) — 다음 실행에서 다시 설치·등록
- 다음: 위 프로세스를 정리해 커밋 여유 ~10GB 를 확보한 뒤 `-memory 4096`(기본)으로 부팅 → 내비 지도 표시 확인 → 위 "다음 실행에서 할 것" 1~6
