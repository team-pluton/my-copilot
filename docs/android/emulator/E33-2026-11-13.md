# E33 — 출품 APK 공조 현재값 수정 검증 (2026-11-13, Pleos Connect Emulator v2.1.0 · `copilot-submit` · release)

오너 결정(2026-11-13): 실차에 연결돼 있어도 공조 전원의 '현재값'을 시연 차량 기본값으로 판단해 "공조 켬 · 이미 맞음"이라고 말하던 결함을 **최소 수정**한다. 다른 기능은 바꾸지 않는다. 테스트 · 에뮬레이터 · 설치가 모두 통과할 때만 APK 를 바꾼다.

## 결함과 수정

- 원인: `CopilotSession.cabinPlan` 이 실내 비교의 현재값을 만들 때 공조 전원은 `s.vehicle.hvacOn`(시연 차량 값), 핸들 열선은 `car.steeringHeat`(모의 기본값 false)를 썼다. 공개 SDK 경로로 이 둘을 **읽지 않는데도** 실차 연결 중에 그 값이 '지금 값'이 됐다 — 정책 4(모의와 실제를 섞지 않는다) 위반. 같은 종류라 둘 다 고쳤다.
- 수정: 실차 공조 · 도어 콜백을 받는 중(`cabinLive`)이면 두 값을 `null`(모름) → 비교 결과 "지금 값을 읽지 못함 · 차량에서 직접 확인" · 적용 후보에서 빠짐. 모의(시연 데이터로 표시되는 화면)는 그대로.
- 범위: Kotlin 1줄 + 회귀 테스트 1개. TS 거울에는 실차 연결 경로가 없어(웹 시연은 모의 전용) 같은 수정이 필요 없다. 판단 규칙 · 화면 구성 · 다른 기능 변경 없음.
