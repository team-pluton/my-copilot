# 시연 시나리오 · 음성 안내 문구 · 미충족 설명 규칙

시연 영상(3~5분)과 심사장 PT 가 같은 대본으로 돈다. 수치는 기본 시나리오
(서울→부산 400km · 배터리 68% · 외기 6°C · 공조 ON · 도착 후 대기 40분 · 최소 잔량 20% ·
동승자 어린이 + 반려동물)이고 **전부 가상·가정값**이다. 화면에 늘 "모의" 가 떠 있어야 한다.

## 2. 음성 안내 문구 (TTS) — 확정

규칙: **한 문장에 하나**. 숫자는 하나만. 명령형 대신 제안형. 주행 중에는 질문하지 않는다
(답하려면 화면을 봐야 한다). 길이는 12초 안.

| 상황 | 문구 |
|---|---|
| 출발 전 · 부족 | "도착 후 대기까지 배터리가 모자랄 수 있어요. 정차 중에 경로상 충전·휴식 후보를 보여 드릴게요." |
| 출발 전 · 아슬아슬 | "도착 후 대기까지 아슬아슬해요. 쉬어 가는 김에 짧게 충전하면 여유가 생겨요." |
| 출발 전 · 충분 | "충전 없이 도착할 수 있어요. 휴식만 계획할게요." |
| 주행 중 · 경유지 50km 전 | "{장소} 가 {N}km 앞이에요." |
| 주행 중 · 경유지 10km 전 | "{장소} 가 {N}km 앞이에요. 오른쪽 차로를 이용하세요." |
| 주행 중 · 휴식 시점(SUGGEST) · 경유지 없음 | "{N}분 달렸어요. 다음 휴게소에서 쉬어 가면 좋겠어요." |
| 경유지 도착 | "{장소} 에 도착했어요. 80% 까지 약 {M}분 걸려요. 그동안 쉬세요." |
| 픽업·마중 · 충분 | "귀가까지 충분해요. 공조 켜고 약 {N}분(2시간 이상이면 {H}시간)까지 기다려도 돼요." |
| 픽업·마중 · 부족 | "돌아오는 길까지 배터리가 모자랄 수 있어요. 출발 전에 충전해 두세요." |
| 내비 응답 없음 | "내비게이션 응답이 없어요. 지금 경로는 그대로예요." |
| 내비 목적지 없음 | "내비게이션에 목적지가 없어요. 목적지를 먼저 설정한 뒤 경유지를 추가해 주세요." |
| 슬롯 꽉 참 | "경유지 두 개가 모두 찼어요. 기존 경유지는 그대로 두었어요." |

시연의 `voice` 문자열(`simulator.tsx`)은 이 표의 문구를 쓴다. 바꾸면 표도 같이 고친다.
주행 중 화면의 스피커 버튼은 **브라우저 TTS**(Web Speech, ko-KR 음성이 있으면 그것)로 읽는다 — 시연용이고, 실제 앱은 Pleos TextToSpeech SDK v3.3.1 이다.

## 3. 미충족 설명 규칙

- 선호 시설이 없으면 **"{시설} 없음"** 으로 적는다. 숨기지 않는다. 둘 이상이면 쉼표.
- 전부 있으면 **"선호 시설 모두 있음"**.
- 필수 시설이 없는 곳은 설명하지 않는다 — 후보에 오르지 않는다.
- 정보가 미확인이면 이유 끝에 **"정보 미확인"** 을 붙이고 점수에서 신뢰도 축이 40 으로 깎인다.
- 우회 **시간**은 재계산에 성공했을 때만 "추가 N분". 거리는 항상 "경로에서 N km".
- 충전 필요 여정에서는 **"도착 시 약 N%"** 와 **"충전 후 끝까지 충분 / 충전해도 한 번 더 서야 함"** 을 이유에 넣는다.
