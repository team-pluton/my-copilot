### 선택 제출물 — 가산점

| 항목 | 규칙 |

| 시연 영상 | 목업 · 프로토타입 · **화면 녹화 인정** |
| GitHub 저장소 | **소스 + APK 함께**(APK 만 따로 내지 않는다). APK 는 `apk/` 폴더, 이름 `팀명_앱이름_release.apk`, **실행 가능한 release**. 크면 GitHub Releases 주소 |
| 비공개 저장소 | 가능 — 공지될 **심사용 GitHub 계정을 Collaborator 로 초대**, 마감 전 접근 확인. 개인 계정 비공개 저장소는 Collaborator 에게 **쓰기 권한**도 간다 |
| README.md | 앱 이름·한 줄 소개 · 실행 방법 · 테스트 환경·필요한 설정 · APK 위치 또는 Release 링크 |

## 참가 자격·규정

- 대학(원)생 · 일반인 · 스타트업, 개인 또는 팀(대표 포함 최대 5인). 부문: 대학생 / 일반(스타트업 포함).
- 현대자동차그룹 임직원은 참가는 되지만 수상 제외.
- **제출 서류 내용이 사실과 다르면 선정 취소.** 표절·타 공모전 수상작 제외. 제3자 권리(초상권·저작권·디자인권) 침해 책임은 응모자.
- IP 는 응모자. 수상작은 주최측 통상실시권 · 결과 발표 후 4개월 우선협상권 가능.
- 상금은 대표 신청자에게 일괄, 제세공과금 원천징수.

## 숏폼 챌린지 (선택 · 가산점 없음)

30초~1분 **세로** 영상(릴스·쇼츠)으로 아이디어나 시연 화면. Instagram 릴스 또는 YouTube Shorts 에 게시.
해시태그 **`#HMG차량용앱개발공모전` 필수** + 총 2~3개(제안 `#PleosAppMarket` `#HMG앱공모전`). 링크는 접수양식 8번.
영상은 시상식에서 쓰일 수 있다.

## 개발 환경 (공식)

Android API 28+ · Gradle 8.0+ · Java 또는 Kotlin. SDK: Vehicle · NaviHelper · TextToSpeech · SpeechToText · FusedLocation.
에뮬레이터로 구동 검증. 예시(참고용): 음성 메모 · 안전운전 점수 · 배달 기사용 앱.

## 공모 분야

공식 홈페이지 문구는 "차량 데이터·기능·이동 상황을 활용한 운전자·탑승자 대상 앱 — 출퇴근·여행·**충전**·주차·**반려동물 동반** 등 자유 주제".
**공식 "고객 니즈 · 페인포인트" 문구**(`/guide/overview`, 2026-10-28 직접 확인 — 예시이며 주제 한정 아님): ① **모빌리티 & 라이프 편의** "주행 중에도 끊김 없는 주문 · 픽업 · 주차 등 일상 서비스 경험" ② **인카 엔터테인먼트** "주행 맥락과 결합된 몰입형 미디어 · 사운드 경험" ③ **스마트 드라이빙 & 안전** "차량 이상 징후의 조기 인지와 실시간 안전운전 피드백" ④ **패밀리 & 동승자 케어** "장거리 이동을 즐겁게 만드는 어린이 · 가족 동승자 케어" ⑤ 그 밖의 주제.
공모전 소개 문구: "차량 데이터와 기능, 이동 상황을 활용해 운전자와 탑승자에게 새로운 경험을 제공하는 앱 서비스" · 순간 예시 "출퇴근, 여행, 충전, 주차, 가족과의 이동, 반려동물 동반, 휴식, 업무".
(보도의 표기 "모빌리티 라이프 케어 · 안전 운전"은 공식 문구와 다르다 — 공식 것을 쓴다.)
쉼표 DRIVE 는 **① 모빌리티 & 라이프 편의 + ④ 패밀리 & 동승자 케어**, 순간 예시 중 **충전 · 여행 · 반려동물 동반** 셋에 걸친다. MY CO-PILOT 의 대응표는 `docs/my-copilot/FIT-2026-10-28.md`.

## 이 문서가 바꾼 전략 (2026-10-25)

1. **PT 에 실제 앱이 필요하다** → 웹 시연만으로는 2차를 치를 수 없다. Android 앱(`android/`)과 release APK 를 1차에 같이 낸다(가산점).
2. **양식이 DOCX 다** → 웹 기획서(/proposal)는 원재료이고, 제출본은 양식 02 에 옮긴 것이다(`docs/submission/`).
3. **익명 심사** → 02·링크·첨부에서 실명·GitHub 계정명을 지운다. 저장소는 비공개 + 심사 계정 초대로 낸다.
4. **사실과 다르면 취소** → 시연 데이터의 "실제" 주장은 출처로 다시 확인한다(죽암 반려견 놀이터는 **서울방향**이었다).
